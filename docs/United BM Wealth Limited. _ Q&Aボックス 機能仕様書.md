# United BM Wealth Limited. / Q&Aボックス 機能仕様書

本ドキュメントは、対象サイト（`https://qaboxai-dv56bra3.manus.space/`）のリバースエンジニアリング結果に基づき、同等のシステムを再現するための機能仕様を定義するものです。

## 1. システム概要

本システムは、オフショア金融商品（RL360、ITA、サンライフ香港など）に関する質問に対して、あらかじめ構築されたナレッジベースからAIが自動回答を提供するチャットボット型Q&Aシステムです。主な特徴として、ナレッジベースに基づき根拠（参照元）を明示した回答を生成するAI自動回答機能、AIが回答できない場合にユーザーが直接一次代理店（GP）に問い合わせできるエスカレーション機能、そしてブラウザのセッションストレージを利用してユーザーの会話履歴を保持するセッション管理機能が挙げられます。

## 2. UI構成

システムはシングルページアプリケーション（SPA）として構成されており、シンプルで直感的なインターフェースを提供しています。

| 構成要素 | 詳細 |
| :--- | :--- |
| ヘッダー | 画面上部に固定されたヘッダー内に、United BM Wealth Limited.のロゴ画像が配置されています。ロゴをクリックするとチャット履歴がクリアされ、初期状態に戻ります。 |
| 初期画面 | 「質問ボックスへようこそ」「オフショア金融商品に関するご質問にAIがお答えします。」といった案内文が表示されます。また、ユーザーがクリックするだけで質問を送信できる6つのサジェストボタンがグリッド状に配置されています。 |
| チャット画面 | ユーザーの質問（右寄せ・プライマリーカラー）と、AIの回答（左寄せ・グレー背景）が吹き出し形式で交互に表示されます。AIの回答はMarkdown形式でレンダリングされ、リストや太字、根拠となるナレッジベースの参照元が見やすく表示されます。 |
| 入力エリア | 画面下部に固定された入力欄で、「ご質問を入力してください...」というプレースホルダーが表示されます。Enterキーで送信（Shift+Enterで改行）が可能です。回答生成中は「回答を生成中...」というスピナー付きのインジケーターが表示されます。 |

## 3. チャット応答フローとエスカレーション機能

チャットの応答フローは、ユーザーが質問を送信するところから始まります。フロントエンドは、質問内容とセッションストレージで管理されている`sessionId`を付与してバックエンドAPIを呼び出します。バックエンドはナレッジベースを検索し、回答を生成して返却します。レスポンスには、AIの回答テキスト、ナレッジベースから適切な回答が生成できたかどうかの真偽値、そして回答の確信度が含まれます。

AIが回答できなかった場合（確信度が低い場合）、フロントエンドはAIの回答の下に「GPに直接質問する」というボタンを表示します。このボタンをクリックすると、チャット履歴内にインラインで問い合わせフォームが展開されます。

| フォーム項目 | 入力形式 | 必須要否 | 詳細 |
| :--- | :--- | :--- | :--- |
| 一次代理店名 | ドロップダウン | 必須 | APIから取得した代理店一覧（20件以上）から選択します。 |
| お名前 | テキスト入力 | 必須 | 最大200文字まで入力可能です。 |
| メールアドレス | メールアドレス入力 | 必須 | 形式バリデーションがあり、最大320文字まで入力可能です。 |
| ご質問内容 | テキストエリア | 必須 | 最大5000文字まで入力可能です。初期値としてユーザーが入力した元の質問がセットされます。 |

フォーム送信時、入力データはバックエンドAPIに送信され、送信成功後には担当者名を含む完了メッセージが表示されます。

## 4. ファイルアップロード機能

UI上にはファイルアップロード用のボタンやドラッグ＆ドロップエリアは存在しません。また、JavaScriptバンドル内を詳細に解析した結果、`FileReader`、`FormData`、`multipart/form-data`などのファイルアップロードに関連する実装コードは見つかりませんでした。結論として、現在のシステムには**ファイルアップロード機能は実装されていません**。

## 5. 技術スタック

フロントエンドおよびネットワークトラフィックの解析から、本システムは以下の技術スタックを利用して構築されていることが判明しました。

| カテゴリ | 技術・ツール | 詳細 |
| :--- | :--- | :--- |
| フロントエンド | React, Vite | シングルページアプリケーション（SPA）として構築され、ビルドツールにViteを使用しています。 |
| UI/スタイリング | Tailwind CSS, shadcn/ui | ユーティリティファーストのCSSフレームワークと、Radix UIベースのコンポーネントライブラリを使用しています。 |
| ルーティング | wouter | 軽量なReactルーターを使用しています。 |
| その他のライブラリ | Lucide React, react-markdown, Sonner | アイコン、Markdown描画、トースト通知にそれぞれ使用されています。 |
| 状態管理・通信 | TanStack Query, tRPC | 状態管理とデータフェッチにReact Queryを使用し、バックエンドとの型安全な通信にtRPCを利用しています。 |
| データベース | Prisma | JavaScriptバンドル内にPrismaのエラーハンドリングコードが存在することから、ORMとして使用されていると推測されます。 |
| インフラ | Cloudflare, Amazon CloudFront | ホスティングおよびCDNとしてCloudflareを使用し、画像などのアセット配信にCloudFrontを利用しています。 |

## 6. APIエンドポイント

システムはtRPCを利用しており、単一のエンドポイント（`/api/trpc/*`）に対してプロシージャ名を指定してリクエストを送信しています。

| プロシージャ名 | メソッド | 用途 |
| :--- | :--- | :--- |
| `qa.ask` | POST | ユーザーからの質問の送信と、AIからの回答の取得に使用されます。 |
| `qa.history` | GET | セッションIDに基づく過去のチャット履歴の取得に使用されます。 |
| `agents.list` | GET | 問い合わせフォームで選択する一次代理店一覧の取得に使用されます。 |
| `inquiry.submit` | POST | ユーザーが入力した問い合わせ内容の送信に使用されます。 |
