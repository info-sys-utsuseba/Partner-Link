## Q: 研修実施時、クライアント様の一時的な負担額はどれくらいになりますか？

**質問者:** [代理店B]（YU-KI様） / **日付:** 2026-02-27 / **タグ:** #料金 #助成金 #クライアント負担

**質問内容:**
> こちらの研修を通して行うと、一時的なクライアント様の負担はどれくらいになりますか？

**回答:**
一時金で一人当たり 400,000 円（税抜き／税込 440,000 円）をご負担いただきます。その後、約半年後に 75% 補助されるため、300,000 円が国よりバックされ、実質手出しは税込で約 140,000 円となります。ややこしいので、お客様には「手出し 100,000 円」とご案内しております。さらに節税効果を加味しますと、実質負担は 0 円という整理も可能です。
