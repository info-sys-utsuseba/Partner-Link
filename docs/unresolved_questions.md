# 未解決・要フォロー質問リスト

本リストは、LINE 公式アカウントのログにおいて運営側が即答できず「確認します」「少々お待ちください」等で保留にした質問、または社内で追加ナレッジ化が必要と思われる論点を抽出したものです。自律ナレッジ改善ループの初期インプットとしてご活用ください。

## 1. AI 研修資料の社外シェア可否の即答フロー整備

- **質問者:** [代理店C]（Jennie様）
- **日付:** 2026-02-11
- **原文（匿名化後）:** > こちらは企業にシェアして宜しいものでしょうか？お忙しい所大変痛み入ります。シェアはして差し上げても宜しいでしょうか？
- **運営側の反応:** takahiro「お返事遅れて申し訳ございません。確認いたします。少々お待ちください」→ 3 日後に大越朝より「資料は共有大丈夫です」と返答
- **ステータス:** 対応済だが回答まで 3 日要したため、FAQ 化推奨
- **示唆される欠落ナレッジ:** 各種資料（報酬制度 PDF／損金スキーム PDF／代理店報酬 mp4／AI研修動画 mp4／Canva 資料）ごとの「社外シェア可否」マトリクスが未整備。代理店に配布する時点で「これは二次配布可」「これは社内限」のラベル付けを行う必要がある。
